## Short Description

Manage subjects, tasks, attendance, classes, date sheets, and reminders in one student planner.

## Full Description

QuizMate is a smart semester manager for students. It helps you organize your academic life in one clean and simple app.

With QuizMate, you can:

- Create a student account with email or registration number
- Add theory and lab subjects
- Manage quizzes, assignments, projects, and deadlines
- Track attendance for every subject
- View attendance percentage with color indicators
- Add class schedules with day, time, and room
- Get class reminders before class starts
- Manage date sheets with paper date, time, room, and subject type
- Receive deadline and paper reminders
- View upcoming class, upcoming paper, deadlines, and attendance overview on Home
- Save alerts inside the Alerts section
- Set up your profile with basic student details and profile picture
- Use dark mode and responsive layouts

QuizMate is designed to keep student planning simple, clean, and useful.
